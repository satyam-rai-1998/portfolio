Case study · GISP Assistant for supply planning

How can a supply planner check backorders with Copilot Studio?

A planner asks GISP Assistant which materials have the largest backorders at a plant. Copilot Studio passes the question to the Microsoft Fabric data agent I built on the Power BI semantic models behind the global supply chain report. The planner can then ask which of those materials have production scheduled.

How does the question reach the report?

I built the data agent and connected it to the conversational agent. The service model supplies backorder value, inventory and available-to-promise status. The production model supplies forecasts, targets and work orders. For a question with two parts, the assistant can identify the affected materials first and use that list to look up production coverage.

Which backordered material needs a closer look?

Example question. “At Plant A, which material has the highest backorder value this week, and is production planned for it?”

Illustrative answer using fictional data. Material M-101 has $24,000 in backorders, ahead of M-204 at $16,000. The sample production plan shows a work order for M-204 this week and none for M-101. A planner could follow up by asking whether another plant holds inventory for M-101.

How does GISP-Auto deliver the scheduled version?

GISP Assistant starts with a planner’s question. For recurring updates, I built GISP-Auto. A Power Automate schedule supplies a plant-specific prompt. The agent retrieves the figures through Fabric, validates and combines the results, formats the report as HTML and delivers it by email and to the appropriate Teams group.
