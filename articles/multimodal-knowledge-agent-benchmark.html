Can a document agent read the chart as well as the caption?

By Satyam Rai · November 18, 2026

A search result can find the right slide and still give an agent the wrong answer. A legend, a footnote or a column heading may be the only clue that two numbers mean different things.

What the benchmark measures

On November 10, 2026, Google and Artificial Analysis introduced the Multimodal Knowledge Agent benchmark. Its 200 tasks draw on work from 83 occupations across 10 industries. The evaluation gives models a common set of tools and the same turn budget. The tasks ask an agent to use visual material across files to produce work someone can inspect. Google’s Multimodal Knowledge Agent benchmark report.

Build a small version for invoice review

Take a synthetic invoice whose line items and tax appear on one page and whose revised total appears on another. Include a credit note with a similar invoice number. Ask the assistant for the amount due, the invoice identifier and the page supporting the figure. Give it a second case with different column positions. This tests whether it follows the labels when the layout changes.

Score the evidence separately

Award one point for choosing the right document, one for returning the right value and one for pointing to the page that supports it. These scores separate a retrieval problem from a reading problem. A correct number with the wrong page is especially useful to investigate before trusting an assistant with a larger document collection.
