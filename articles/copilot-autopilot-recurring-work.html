Copilot Autopilot gets its own identity for recurring work

By Satyam Rai · November 18, 2026

A Friday status report sounds easy to delegate. The harder question is who owns the follow-up when an agent is still working on Monday. Microsoft’s Ignite rollout makes that question concrete.

What Microsoft announced

On November 17, 2026, Microsoft began rolling out Autopilot to Frontier customers. It described an agent that can monitor a Teams channel, follow up on email and carry a recurring assignment across sessions. Each Autopilot has an Entra Agent ID and a named manager. Administrators can limit its access, block it and review actions recorded under its identity. Microsoft’s Ignite announcement.

A Friday report that can survive a Monday correction

Consider a weekly project digest. Give the agent access to one project channel and ask it to draft a report with links to the messages behind each milestone. A project owner reviews the draft before it goes to a wider group. That division gives the agent a recurring job and gives readers someone to contact when a conclusion is wrong.

The handoff worth rehearsing

Suppose the owner transfers to another team on Thursday. Can the replacement find the assignment, see which channels it reads and pause Friday’s delivery? A pilot that rehearses that handoff tells you more about running a persistent agent than a single polished summary.
