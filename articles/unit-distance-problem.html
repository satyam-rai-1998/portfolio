What an AI model found in the Erdős unit distance problem

By Satyam Rai · 2026-06-07

A reasoning model found arrangements of points with more unit-distance pairs than mathematicians had expected. The result gives agent developers a concrete example of how to check a generated answer.

What did the model find?

Place points on a plane and count the pairs exactly one unit apart. How large can that count get as you add points? In May 2026, OpenAI reported that a model constructed families of point sets that beat the conjectured bound. External mathematicians checked the proof. Read the research announcement and proof.

How does that apply to a support agent?

Give the agent a question with a checkable outcome. For a ticket-status request, compare the answer with the ticket record. For a request to update the ticket, inspect the saved change. These two tests catch different failures even when the agent’s replies sound equally convincing.
